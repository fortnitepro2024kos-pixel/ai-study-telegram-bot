# 📚 Study Assistant Telegram Bot

An asynchronous Telegram bot built with Python (aiogram 3) designed to help with studying: generating summaries, solving math/study problems from photos, translation, and creating "handwritten" notes.

## 🛠 Tech Stack
- **Python 3.11+**
- **Aiogram 3.x**
- **Google Gemini API**
- **Redis** (FSM, session storage, rate limits)
- **Pillow & ReportLab** (image processing and PDF generation)
